# rod-assets-browser-hook

browser-hook -- Browser hook script for the Browser implant class: the served JavaScript client the hook mint renders with a per-hook bake.

A Rod asset module (entry kind: assets) in the
[Rod](https://github.com/rodframework/Rod) ecosystem: content the
teamserver renders or serves without executing. The manifest
(`rod-module.toml`) is the contract; the package installs from the
[rod-registry](https://github.com/rodframework/rod-registry) index:

    rod mod install browser-hook
